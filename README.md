# Proyecto_Sistema_Transmision_Recepcion_Luz-Infrarroja

Objetivo general: diseñar e implementar un sistema de comunicación digital mediante luz infrarroja capaz de capturar, almacenar, analizar, reconstruir y transmitir señales IR, utilizando el STM32F334R8 como unidad de procesamiento.

La idea final será poder capturar la señal de un control remoto,procesar la señal para posteriormente generar una señal equivalente desde el STM32 para controlar un dispositivo compatible.
